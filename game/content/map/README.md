# 基础地图预留目录

本目录目前只有本导航，没有可供运行时加载的基础地图数据。旧版 `read_map`、`world-map.json` 回退描述不再作为当前实现说明。

基础场景见[默认世界卡](../packs/grey-crow-default/world/WORLD.md)；地图能力内容源在[skills/map](../skills/map/)，是否实际接入看[桌面会话桥](../../engine/bridge/session-desktop-bridge.js)与[会话源码](../../engine/session/)。玩家当前位置与已发生的变化由正式状态管理。

新增地图数据或地图玩法属于另行确认的工作，不因保留此目录自动启动。产品范围见 [PRODUCT.md](../../../PRODUCT.md)，内容加载流程见[内容导航](../README.md)。
