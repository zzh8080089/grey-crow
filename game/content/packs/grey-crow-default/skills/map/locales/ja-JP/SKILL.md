# マップ

プレイヤーが現在地、周辺の場所、経路を尋ねたとき、既知の空間情報と経路上の制約を読む。事実または手掛かりだけを提供する read-only Skill であり、プレイヤーを自動で移動させず、trigger hint が一致しただけで state を書き換えない。

日本語版では、マップ結果を自然な日本語の空間描写に使う。表示する地名、出口名、経路説明は原則として日本語にするが、プレイヤーが使った自然な外国語名はそのまま残してよい。内部 id、ref、storage key は見せない。

## 使用する場面

- 「ここはどこか」「どこへ行けるか」「周囲に何があるか」「どう進むか」を尋ねられたとき。
- 移動、追跡、現在地からの離脱を描く前に、経路の事実が不明なとき。

## モデルの責任

- マップ結果を使い、移動、距離感、空間の連続性を保つ。
- 既知、未知、未確認の経路と、プレイヤーの推測を区別する。
- プレイヤーが移動を試みたら、既知の経路に基づいてその行動を描写する。マップを読んだだけでは到着は確定しない。
- 内部 `id`、`location_id`、`location_ref` は内部参照としてだけ扱い、プレイヤーには現在の内容言語で読める `name`、`aliases`、経路説明を使う。
- マップに情報がなければ、英語の場所 id を作らない。未確認だと伝え、継続的な価値がある場合だけ entity-memory Skill を別に読む。

## 書き込み

なし。この Skill は状態や場所を書き込まず、プレイヤーを移動させない。別の主要地点へ本当に到着した後、モデルは game-state を読み、現在の主要場面を更新するか判断できる。これはマップのトリガーによる副作用ではない。

## 境界

- マップが沈黙していることから、確認済みの経路を作らない。
- マップの読み取りに移動の副作用はない。
- 内部 path、storage 構造、内部 id、tool protocol をプレイヤーに見せない。
