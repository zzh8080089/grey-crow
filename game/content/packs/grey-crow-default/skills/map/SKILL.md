# 地图

当玩家询问当前位置、附近地点或路线时，地图读取已知空间资料和路线约束。它只提供事实或
线索。本 Skill 是只读的，不会自动移动玩家，也不会因为触发提示命中而自动写状态。

当前中文版规则：地图结果用于支撑中文空间叙事。玩家可见地点名、出口名、路线说明默认使用中文自然语言；自然英文 / 其他语言地点名可以保留为玩家可见名。内部 id / ref / storage key 不能说给玩家。

## 何时使用

- 玩家询问“这里是哪里”“能去哪”“周围有什么”“路线怎么走”时读取。
- 旅行、移动、追踪或离开当前地点前，如果路线事实不清楚，先读取。

## 模型职责

- 用地图结果保持移动、距离感和空间叙事连续。
- 区分已知路线、未知路线、未确认路线和玩家猜测。
- 如果玩家尝试移动，先结合已知路线主持这次行动；地图读取本身不决定玩家是否到达。
- 读到内部 `id`、`location_id`、`location_ref` 时，只把它当作内部引用；对玩家使用当前内容语言下的可读 `name` / `aliases` / 路线说明。
- 如果地图沉默，不要制造英文地点 id。可以说信息未确认；有持续价值时再另读实体记忆 Skill。

## 写入

无。本 Skill 不写状态、不写地点、不移动玩家。玩家确实到达另一个主要地点后，模型可以另读
`game-state` 并决定是否更新当前主要场景；这不是地图触发产生的副作用。

## 边界

- 不从地图沉默中创建已确认路线。
- 读取地图不会产生移动副作用。
- 不向玩家暴露内部路径、存储结构、内部 id 或工具协议。
