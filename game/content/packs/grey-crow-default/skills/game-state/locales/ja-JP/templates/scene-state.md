# 場面状態の template

Template ID: `template:scene-state`

プレイヤーが別の主要地点へ到着したときに使う。同じ建物、街区、主要地点内の短い移動では、通常は主要場面を更新しない。

`confirm_current_location` の parameter の例：

```json
{
  "location": "<プレイヤーに表示する主要地点名>"
}
```

規則：

- 主要場面の基点または強制された地点が変化したときだけ、現在地を書く。
- 同じ場面内の姿勢、遮蔽、視点、音、感情、雰囲気は、主に物語または補助的な記録に属する。
- `location` はプレイヤーに表示する名称であり、日本語版では自然な日本語を優先する。固有名詞は元の言語を保ってよい。
- 詳細な場所、経路、存在する対象は世界記録に属する。継続する場所の詳細は `entity-memory` を使う。
- Runtime が revision、冪等性、UI への反映を担当する。reference、要約、tag、内部 field を追加しない。
