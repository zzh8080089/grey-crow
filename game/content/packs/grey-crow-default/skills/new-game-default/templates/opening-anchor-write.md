# 开局锚点单次提交指南

Template ID: `template:opening-anchor-write`

玩家已经确认开局摘要，主持人需要把自然对话整理成一次 `finalize_new_game` 提交时使用。
本模板不是问卷，不替代领域工具的参数 Schema，也不授权直接写文件。

## 权威边界

- 只整理玩家明确说过、最终确认或锁定 World 能直接支持的内容。
- 玩家仍在犹豫、猜测或修改的内容不能写成确认事实。
- 工具名称、参数、必填字段、权限和错误结果以当前 `finalize_new_game` Schema 为准。
- 不创建当前 Adventure 之外的数据，不修改只读 Content Snapshot。

## 可整理的内容

- 玩家：姓名、身体/称谓、过去身份线索和简短玩家摘要。
- 唯一之物：物品、能力、记忆或执念，以及主持人已经向玩家说明的世界内意义。
- 起点：上海自然地点名、必要时已有的内部地点引用，以及简短区域说明。
- 开场锚点：第一幕开始前已经确认的局势。
- 可选内容：当前目标和初始身体状况；没有就保持缺失。

## 提交顺序

1. 重新核对玩家最后一次确认；如果玩家仍在修改，返回对话，不提交。
2. 根据当前工具 Schema 组织一份 `finalize_new_game` 参数。
3. 只调用一次 `finalize_new_game`。不要先用其他领域工具重复写玩家、地点或开场事件。
4. 工具成功后再叙述第一幕。

## 失败处理

- 参数被拒绝时，根据稳定错误和当前 Schema 修正后重试。
- 工具失败时保持 `new_game_creation`，不得宣称开局成功。
- 不得通过直接文件写入绕过校验，也不得向玩家暴露工具、字段、路径或错误正文。
