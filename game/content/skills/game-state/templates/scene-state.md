# 场景状态模板

Template ID: `template:scene-state`

玩家已经到达另一个主要地点时使用。同一建筑、街区或主要地点内的短距离动作，
通常不更新场景锚点。

调用 `confirm_current_location`，参数：

```json
{
  "location": "<玩家可见的主要地点名称>"
}
```

规则：

- 只有主要场景锚点或强制地点变化需要写当前位置。
- 同一场景内的姿态、遮蔽、视角、声音、情绪和氛围变化主要属于叙事或软记录。
- `location` 是玩家可见名称；当前中文版优先自然中文，但专有名词可以保留原语言。
- 详细地点、路线和在场实体属于世界记录；持续地点细节使用 `entity-memory`。
- Runtime 负责版本、幂等和 UI 投影；不要附加 reference、摘要、标签或内部字段。
