# 灰鸦 · Grey Crow

[简体中文](README.md) | [English](README.en.md) | 日本語

自然な言葉で行動する。あなたの選択は、物語の記憶になる。

Grey Crow はローカル優先のデスクトップ型テキストアドベンチャーです。プレイヤーは主人公として登場人物と会話し、環境を探索し、約束を交わし、その選択がもたらす結果に向き合います。標準シナリオは、上海で感染が広がり始めてからおよそ10日後を舞台に始まります。

ゲームはプレイヤーと AI の対話によって進行します。体力値、攻撃力、隠しスコアで行動を裁定する仕組みはありません。人物の身体状況、既知の事実、関係性が物語の制約になります。一方でモデル生成には不確実性があるため、物語の一貫性と長期記憶は実際のプレイを通じて継続的に検証する必要があります。

> プロジェクトは現在プレイヤーテスト中です。実装済みの機能、自動チェックの通過、正式リリースの受け入れはそれぞれ別の状態です。現時点では、安定版の提供や全プラットフォーム対応を約束していません。

## 遊び方

- **自由に行動を表現する**：言いたいことやしたいことをそのまま書けます。コマンドを覚える必要はありません。
- **物語に残った変化を確認する**：日記帳のサイドバーでは、人物、資料、状態、章の振り返りを確認できます。重要な出来事は、以後のコンテキストと記憶検索に反映されます。
- **保存して続ける**：冒険ごとに個別保存され、再開、章の振り返り、物語のエクスポートに対応しています。
- **話して物語を聞く**：ローカルで動作する中国語・英語・日本語の音声入力を任意で使えます。中国語の読み上げには4種類の声を用意しています。認識されたテキストは、プレイヤーが確認してから送信します。
- **少しずつ画面に慣れる**：入門チュートリアル、DeepSeek の登録案内、ゲーム内の段階的なオーバーレイガイド、設定からの再表示・リセットを用意しています。

インターフェースは簡体字中国語、英語、日本語と、明暗2種類の日記帳テーマに対応しています。言語と視覚表現については、引き続きプレイヤーと母語話者からのフィードバックが必要です。

## モデルとリソース

**ソースコードのリポジトリには、物語生成モデルやローカル音声モデルの重み、API キー、無料の API 利用枠は含まれていません。** モデル選択とカスタム接続の設定は、モデルサービスへの接続を指定するもので、モデル本体を提供するものではありません。

- **物語生成**：自分で設定したモデルサービスと API キーを使用します。接続テストやプレイにはサービス提供元の料金が発生する場合があります。
- **音声入力と読み上げ**：ソースには連携コードとリソースの準備手順が含まれます。開発者はモデルの重みと対象プラットフォームの実行コンポーネントを別途用意する必要があります。メンテナーが別途提供する Windows 向け完全テストパッケージにはローカル音声リソースが含まれますが、ソースコードのダウンロードには含まれません。

## テストを始める

テストパッケージはメンテナーから別途提供されます。Windows 向け完全テスト ZIP を受け取ったら、まずすべて展開してから、中の `Grey Crow.exe` を実行してください。実行ファイルだけをコピーしないでください。完全版の音声パッケージにはローカル音声認識と中国語読み上げに必要なリソースが含まれているため、Python の追加インストールやモデルのダウンロードは不要です。署名されていないテストパッケージでは、発行元不明の警告が表示されることがあります。

初回起動時は、チュートリアルに従って設定画面で自分のモデル API キー（モデルサービスを呼び出すための認証情報）を入力し、「テストして使用」をクリックしてから冒険を作成します。既存のセーブデータがある場合は、続きを選べます。

**ローカル優先は完全オフラインを意味しません。** セーブデータと設定は端末に保存されますが、物語の生成では必要な物語コンテキストが、プレイヤーが選んだモデルサービスへ送信されます。接続テストやプレイによりサービス提供元の料金が発生する場合があります。音声認識とローカル読み上げは端末上で実行されます。プロジェクトは共有キーを提供せず、ソースコードにもクラウド型ストーリーモデルの重みは含まれていません。

プログラムのフォルダーを置き換えても、システムのユーザーディレクトリにあるセーブデータや設定は自動削除されません。問題が起きた場合は設定から「問題レポートを保存」を選び、OS のバージョン、操作手順、表示されたメッセージ、またはスクリーンショットを添えてください。API キー、個人のセーブデータ、録音は送らないでください。

## ソースコードから起動する

ローカル検証環境では Node.js `22.22.1` と npm を使用します。依存関係のインストール、テスト、デスクトップアプリの起動は、いずれも Electron ディレクトリから行います。Electron は本プロジェクトで採用しているデスクトップアプリケーションフレームワークです。

```sh
git clone https://github.com/zzh8080089/grey-crow.git
cd grey-crow/game/apps/desktop/electron
npm ci
npm start
```

`npm ci` は固定された依存関係をインストールし、Electron をダウンロードします。起動後も、ゲーム設定でモデル接続を構成する必要があります。インストール、ソースコードのチェック、接続の検出が成功しても、特定モデルによる物語体験が受け入れ済みであることを示すものではありません。

**ソースコードのクローンには、ローカル音声モデルやプラットフォーム固有コンポーネントは付属しません。** テキストアドベンチャーは先に単独で起動できます。音声を有効にする前に、[音声入力の実行レイヤー説明](game/apps/desktop/electron/speech-input/native/README.md)に従って対象プラットフォームの認識プログラムとモデルを用意し、[読み上げリソース説明](game/vendor/tts/README.md)に従って言語パックを準備してください。認識と読み上げは別々のリソース経路です。

ソースリポジトリには、正式なゲームのコード、コンテンツと素材、ビルドスクリプト、回帰テスト、必要な説明書とライセンスのみを含めます。すべての実験環境、試作案、過去の実験レポート、一時生成物、個人用の開発設定はメンテナーのローカル作業環境で管理します。正式な音声リソースの準備ツールは `game/vendor/tts/` にあります。

初期の正式素材は、埋め込みの生成元情報、過去の制作記録、またはメンテナーによる GPT Image 2 で生成したとの申告に基づき、[ファイル別の出典記録](game/apps/desktop/electron/renderer/assets/provenance.json)に整理しています。メンテナーの申告は独立した検証ではなく、ソースコードのライセンスは素材の追加の再利用権を付与しません。

完全なモデルパッケージの準備、ライセンス表記の保持、確認手順については、[パッケージング・チェックリスト](game/apps/desktop/PACKAGING_CHECKLIST.md)を参照してください。通常の本体ビルドでは Kokoro 読み上げの実行環境は自動生成されません。Windows 向けクロスビルドが通っても、Windows 実機での検証に代わるものではありません。

## 開発チェック

`game/apps/desktop/electron` 内で、変更範囲に応じて実行してください。

```sh
npm run check:session              # セッション、ブリッジ、セーブデータの自動テスト
npm run check:renderer-boundaries  # UI 境界の自動テスト
npm run check:player-guide         # チュートリアル記録とスクリプトのチェック
npm run smoke:ui:game-tour         # 実デスクトップでの UI ガイドチェック
npm run check                     # 完全な標準チェック。デスクトップウィンドウを開きます
```

上記のデスクトップチェックは、分離した一時データと合成モデル応答を使用するため、実際のストーリーモデルのキーは不要です。ウィンドウのフォーカスが互いに干渉しないよう、デスクトップ UI チェックは同時に1組だけ実行してください。音声、記憶、物語の品質、対象プラットフォームでの実際の動作は、それぞれ個別に検証する必要があります。その他の入口は[テスト案内](game/README.md)を参照してください。

## 検討中の方向性

- **WeChat で冒険を続ける**：次の段階では、プレイヤーが PC 上の同じ冒険を WeChat から継続できる、任意かつ独立したメッセージ入口を重点的に検討します。連携、権限、メッセージ順序、分割、エラー応答は未設計です。
- **AI 支援による世界とシナリオの創作**：世界設定、ワールドブック、シナリオ編集を段階的に公開し、MCP（Model Context Protocol：外部 AI からアプリ機能を呼び出すための規約）または類似のインターフェースで創作ツールへ接続することを検討しています。具体的な範囲、インターフェース、認可方法は未定です。

これらは今後の検討事項であり、現時点で正式な WeChat 連携や公開された MCP 創作サービスはありません。既存のコンテンツ管理コードが、汎用的なワールドエディターとして公開済みであることを意味するものではありません。
